# HolyTGS (Holy Tours and Global Studies)

A modern, high-performance web platform for **Holy Tours and Global Studies (HolyTGS)** — a premier study abroad and international travel consultancy.

Live Website: [https://holytgs.vercel.app](https://holytgs.vercel.app)

---

## 🚀 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

---

## ✨ Features

- **Cinematic Hero Banner**: Smooth slideshow with high-key gradient overlay, flight paths with animated airplane, and interactive floating service cards.
- **Trust Stats Ribbon**: Half-overlapped brand blue box with animated 0-to-target count-up statistics.
- **Who We Are**: Dynamic 3-image collage, brand pillars, and official accreditation badges.
- **Our Services**: 8 clean, minimal service cards spanning Career Counseling, Admissions, Visas, Tickets, and Language Courses.
- **Top Destinations**: Full-image destination cards for UK, Canada, and USA with country flags.
- **Responsive Footer**: Real brand logo in a frosted capsule and a signature oversized watermark.
- **100% Mobile Responsive**: Customized mobile UX with proportional typography and layouts.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ installed
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jubayer-ahmed-ratul/holy-tgs.git
   cd holy-tgs
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser.

---

## 📦 Build for Production

```bash
npm run build
npm run start
```
